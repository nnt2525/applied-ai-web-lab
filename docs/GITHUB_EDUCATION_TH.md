# GitHub Education สำหรับนักศึกษา: ใช้ทำเว็บ วิเคราะห์ข้อมูล และวิจัย

อ้างอิงเอกสาร GitHub ทางการที่ตรวจสอบช่วงคืนวันที่ **18–19 ตุลาคม 2026 (Asia/Bangkok)** ข้อเสนออาจเปลี่ยนได้ ให้ตรวจหน้า benefits ของบัญชีอีกครั้งก่อนเปิดบริการ

## สมัครอะไร และใครสมัครได้

สมัคร **GitHub Education / Student Developer Pack** ผ่านบัญชี GitHub เดิม เพื่อขอสิทธิ์นักศึกษา ไม่ต้องซื้อ GitHub Pro ก่อน และไม่ต้องมีผลงานวิจัยเพื่อเริ่มสมัคร

เกณฑ์หลักคืออายุอย่างน้อย 13 ปี มี personal account และกำลังเรียนหลักสูตรที่ให้วุฒิ degree หรือ diploma พร้อมหลักฐานสถานะปัจจุบัน [เกณฑ์และวิธีสมัคร](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student)

นักศึกษาที่ทำวิจัยสมัครด้วยสถานะนักศึกษาได้ ส่วนการเป็นนักวิจัยอย่างเดียวไม่ได้ทำให้มีสิทธิ์ Student Developer Pack; อาจมีโครงการส่วนลดอื่นตามเงื่อนไขของ GitHub [เงื่อนไข Pack](https://docs.github.com/en/education/about-github-education/github-education-for-students/github-terms-and-conditions-for-the-student-developer-pack)

## ขั้นตอนยื่นด้วยบัญชี nnt2525

1. เข้าบัญชีเดิม แล้วเปิด [Education benefits](https://github.com/settings/education/benefits)
2. เพิ่มและยืนยันอีเมลมหาวิทยาลัย หากแบบฟอร์มกำหนด
3. เลือก **GitHub Education → Start an application** และกรอกข้อมูลจริง
4. เตรียมหลักฐานอย่างใดอย่างหนึ่ง: บัตรนักศึกษาที่มีวันที่ปัจจุบัน ตารางเรียน transcript หรือหนังสือรับรองสถานภาพนักศึกษา ภาพต้องอ่านชัดและมีวันที่
5. ส่งใบสมัคร แล้วติดตามสถานะในหน้า benefits เมื่อผ่านจึงเปิดใช้ข้อเสนอที่ต้องการ

ถ้าสถาบันไม่ออกอีเมลมหาวิทยาลัย ให้ใช้เว็บหรือหนังสือทางการอธิบายนโยบาย หากโดเมนไม่ถูกยอมรับ ให้ติดต่อ Education Support พร้อมชื่อสถาบัน เว็บไซต์ และโดเมน [รายละเอียดเอกสารและอีเมล](https://docs.github.com/en/education/about-github-education/github-education-for-students/apply-to-github-education-as-a-student)

เอกสารเบลอ ไม่มีวันที่ หรือยืนยันสถานะปัจจุบันไม่ได้ เป็นสาเหตุที่อาจต้องส่งหลักฐานเพิ่ม อีเมลที่เคยใช้ขอ Pack กับบัญชีอื่นนำมาขอซ้ำอีกบัญชีไม่ได้ เมื่อถูกปฏิเสธให้อ่านเหตุผลและแก้จุดนั้นก่อนสมัครใหม่ [แก้ปัญหาใบสมัคร](https://docs.github.com/en/education/about-github-education/github-education-for-students/solving-problems-with-your-github-education-access)

## GitHub Pro กับ Copilot Student เป็นคนละอย่าง

| สิทธิ์ | ใช้กับงานใน repo นี้อย่างไร |
| --- | --- |
| **GitHub Pro** | Pack แสดงสิทธิ์ฟรีระหว่างเป็นนักศึกษา เพิ่มเครื่องมือ review และ protected branches ใน private repo |
| **Codespaces** | environment สำหรับเว็บ Python และ notebook; โควตา Pro ปัจจุบันคือ 180 core-hours และ storage 20 GB ต่อเดือน |
| **Actions** | รัน lint, tests หรือ data pipeline ซ้ำได้; Pro มีโควตา 3,000 นาทีต่อเดือนตามกติกาการคิด usage |
| **Copilot Student** | ช่วยเขียนและอธิบายโค้ด ต้องเปิดสิทธิ์แยก มี AI Credits และข้อจำกัดการใช้งาน |

ที่มา: [สิทธิ์ Pack](https://education.github.com/pack?sort=az), [GitHub Pro](https://docs.github.com/en/get-started/learning-about-github/githubs-plans), [โควตาแต่ละแผน](https://docs.github.com/en/billing/reference/product-usage-included)

Copilot สำหรับนักศึกษาปัจจุบันใช้ชื่อ **Copilot Student**: code completion ไม่จำกัด แต่ chat/agent มีขีดจำกัด และใช้ auto model selection จึงไม่ควรอิงคู่มือเก่าที่รับประกัน Copilot Pro หรือจำนวน premium requests เดิม [แผน Copilot ปัจจุบัน](https://docs.github.com/en/copilot/get-started/plans)

หลัง Education ผ่าน ให้เปิด benefits → **Free GitHub developer resources for students and teachers → Learn more** แล้วทำตามขั้นตอนเปิด Copilot Student การอนุมัติ Education กับการเปิด Copilot เป็นคนละขั้น และสิทธิ์อาจใช้เวลาหลายวันจึงปรากฏ หากเห็นเฉพาะหน้าชำระเงิน ให้รอก่อนและติดต่อ Support เมื่อปัญหายังอยู่ GitHub ตรวจสิทธิ์ Copilot รายเดือน [เปิดใช้ Copilot Student](https://docs.github.com/en/copilot/how-tos/copilot-on-github/set-up-copilot/enable-copilot/set-up-for-students)

## ใช้กับเว็บ Data และ Applied AI ให้คุ้ม

ตัวอย่างด้านล่างเป็นแนวทางทำโปรเจกต์ ไม่ใช่สิทธิ์หรือผลลัพธ์ที่ GitHub รับประกัน

- **เว็บ dashboard:** ทำความสะอาดข้อมูลด้วย Python/SQL แล้ว export เป็น JSON ให้หน้าเว็บแสดงกราฟและ filter พร้อมอธิบายแหล่งข้อมูล
- **งาน applied AI:** เก็บ baseline, metrics, dataset version และขั้นตอนทำซ้ำ เช่น เปรียบเทียบ rule-based กับโมเดล classification แล้วแสดง confusion matrix บนเว็บ
- **ทำงานร่วมกับอาจารย์:** ใช้ issues บันทึกคำถามวิจัย ใช้ pull request ตรวจการเปลี่ยนวิธีวิเคราะห์ และใช้ release ระบุรุ่นที่นำไปเขียนรายงาน
- **ฝึกเพิ่มเติม:** หน้า Pack มี DataCamp 3 เดือน และ Deepnote Team สำหรับ notebook ร่วมกันขณะเป็นนักศึกษา ตรวจเงื่อนไขของผู้ให้บริการก่อนเปิดใช้ [รายการข้อเสนอ](https://education.github.com/pack?sort=az)

เริ่มเก็บโค้ดและทำ portfolio ได้ทันที เพราะ GitHub Free มี public/private repos แบบไม่จำกัดอยู่แล้ว Pro ช่วยเพิ่มความสามารถบางส่วน [เปรียบเทียบแผน](https://docs.github.com/en/get-started/learning-about-github/githubs-plans)

สำหรับงานวิจัยที่พร้อมเผยแพร่ เพิ่ม `CITATION.cff` เพื่อให้ผู้อื่นอ้างอิงซอฟต์แวร์ได้ และพิจารณาเชื่อม public repo กับ Zenodo เพื่อเก็บ release พร้อม DOI วิธีนี้ไม่ต้องซื้อ Pro [ไฟล์อ้างอิง](https://docs.github.com/en/repositories/managing-your-repositorys-settings-and-features/customizing-your-repository/about-citation-files), [GitHub กับ Zenodo](https://docs.github.com/en/repositories/archiving-a-github-repository/referencing-and-citing-content)

## อายุสิทธิ์และค่าใช้จ่าย

การยืนยันสถานะนักศึกษามีอายุ 2 ปี จากนั้นต้องยืนยันใหม่ สิทธิ์พาร์ตเนอร์มีเงื่อนไขแยกกัน บางรายการต่ออายุไม่ได้ และส่วนใหญ่เริ่มนับเวลาเมื่อเปิดใช้ จึงควรเปิดตอนพร้อมใช้งานจริง [เงื่อนไขสถานะ](https://docs.github.com/en/education/about-github-education/github-education-for-students/github-terms-and-conditions-for-the-student-developer-pack), [การต่ออายุ](https://docs.github.com/en/education/about-github-education/github-education-for-students/solving-problems-with-your-github-education-access)

Pack ไม่ใช่การรับประกัน GPU หรือ cloud compute ไม่จำกัด เครดิตและบริการต้องดูข้อเสนอที่บัญชีแลกได้จริง เมื่อเกินโควตา GitHub อาจคิดเงินหากไม่มี budget ที่เปิด **Stop usage when budget limit is reached** [ข้อจำกัด usage](https://docs.github.com/en/billing/reference/product-usage-included)
